🎯 How to play

1. Select a fruit.
2. Select a fruit next to it to swap.
3. Make a line of 3 or more matching fruits.
4. Complete your collection goal before moves run out.

🌟 Tip: Look for matches near the bottom to create more falling-fruit combos.
